RESULT: VERIFIED

The database refused an update and a delete on requestHistory that were
issued with the application credential through the native driver. The
same credential read requestHistory and wrote sessions in the same run,
so the refusal is the missing privilege and not a failed login. DB-01
layer 3 therefore holds for this credential on this cluster.

What this does not show: that any other credential is restricted (the
retention-operator user and Atlas project administrators are not), or
that the same role exists in another environment. Each cluster has its
own role and needs its own run.
