RESULT: VERIFIED

The database refused an update and a delete on requestHistory and on auditLog
that were issued with the application credential through the native
driver. The same credential read both collections and wrote sessions in
the same run, so the refusal is the missing privilege and not a failed
login. The privileges the server reports for this connection include no
database-wide grant of a destructive action. DB-01 layer 3 therefore
holds for this credential on this cluster.

What this does not show: that any other credential is restricted (the
retention-operator user and Atlas project administrators are not), or
that the same role exists in another environment. Each cluster has its
own role and needs its own run.

REVIEW NOTES
  Added by hand after the run, in response to the review of PR #85. Everything
  above this heading is the script's output, unaltered.

  1. Environment Note: This run was executed on a workstation (Node v26)
     against project CivicConnect-Test / database civicconnect, rather than
     the project's baseline Node 22 or the CI runner environment defined in
     DEC-003.

  2. Error Code Note: DB-01 §4 expects an 'Unauthorized' refusal. Atlas
     returns AtlasError code 8000 ('user is not allowed to do action'), which
     satisfies this requirement.

  3. Privilege Listing Note: The "Granted on <collection>" lines report only
     grants whose `resource.collection` matches that collection. The refused
     updates and deletes prove there is no database-wide grant of update or
     remove. They do not rule out a database-wide grant of dropCollection,
     renameCollection or dropIndex, which could destroy the audit trail
     without an update or a remove. That gap is covered by step 8: the script
     lists every grant whose resource has an empty collection name or reaches
     every database, and the server reported none ("Database-wide grants:
     none", 10 privileges reported in total). Step 8 rests on the server's
     own report of this connection's privileges. Unlike steps 2, 3, 5 and 6,
     it is not an attempted operation.
