ASSERTIONS NOT PROVEN BY ANY NV (decided 2026-10-12 by E. Lindsay: recorded as a gap, no further NV runs)
These assertions are in the specs and pass, but no break in this directory has been shown to make them fail. A pass on them
is therefore not evidence.
  1. E2E-1 step 4, "the request carried an Idempotency-Key in UUID v4 form". NV-76 removed the header, and the server refused
     the step-3 (no-reason) POST with 400 first, so step 4 was never reached. A client sending a malformed key only on the
     second submission would be needed to prove it.
  2. E2E-1 step 4, "the request's If-Match equals the ETag read at step 2, verbatim". NV-77 removed the header, and the
     server refused the step-3 POST with 428 first, so step 4 was never reached.
  3. E2E-1 step 5, "after sign-out a reload gets 401 and shows no request data". NV-80 made the client fake sign-out without
     calling DELETE, and the test failed earlier, waiting for the DELETE, so the reload check was never reached. A server that
     answers 204 but does not end the session has not been shown to fail this step.
