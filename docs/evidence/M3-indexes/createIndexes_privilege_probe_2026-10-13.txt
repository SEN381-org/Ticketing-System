WHY
  The provisioning script's privilege check needs to know the exact set of actions the temporary
  provisioning user must hold. DEC-003 v0.3 names createIndex and listIndexes. Building indexes on an
  empty database (the fresh test database, and later staging) means calling createIndexes on collections
  that do not exist yet. MongoDB's server source checks only createIndex for that command, but Atlas
  applies its own permission layer, which is not documented. Separately, an existing index with the same
  key and name but a different expireAfterSeconds is documented to be refused rather than changed; this
  confirms what Atlas actually returns.

WHAT THIS SHOWS / DOES NOT SHOW
  Every control matched its expected result (steps 0-3, 5, 6a-6c), so the result of step 4 is about the
  question asked and not about a broader or broken credential.
  Shows (question A): on this Atlas test cluster, createIndexes on a collection that does not exist creates
  the collection and the index with createIndex alone (createdCollectionAutomatically true), while an
  explicit createCollection by the same user is refused (step 3). The provisioning role therefore needs
  createIndex and listIndexes only, as DEC-003 v0.3 states; createCollection is not added (decision D2).
  Shows (question B): an index with the same key and name but a different expireAfterSeconds is refused with
  85 IndexOptionsConflict and the existing index is left unchanged (6c). A conflicting sessions TTL index
  cannot be changed by the provisioning script; it is reported and fails the run (decision D10).
  Shows (scope): Atlas accepted createIndex and listIndexes scoped to one database, any collection; the
  server reported exactly those two actions on ccprobe and nothing else.
  Shows (idempotency): a repeated identical createIndexes creates nothing ("all indexes already exist").
  Does NOT show: behaviour on another Atlas tier or server version (the test cluster is a free cluster);
  collection-scoped grants (the role used database scope, any collection); anything about the civicconnect
  database; behaviour under concurrent writes; the effect of a unique index over duplicate keys.

SCRIPT SOURCE (probe-createindexes.mjs, unedited)
  // Probe for the index-provisioning script (TD-004, DEC-003 v0.3 step 5).
  // Question A: on Atlas, does createIndexes on a collection that does not exist yet need the
  //             createCollection action as well as createIndex?
  // Question B: on Atlas, what does createIndexes do when an index with the same key and name
  //             exists with a different expireAfterSeconds?
  // Runs only against the throwaway database "ccprobe" on the test cluster. Touches no
  // civicconnect data. Never prints the connection string, host, user name or password.
  //
  // Usage (from the repository root):
  //   node --env-file=.env.probe <this file> <repository root>/package.json
  import { createRequire } from 'node:module';
  import dns from 'node:dns';
  
  const require = createRequire(process.argv[2]);           // repo package.json -> the project's driver
  const { MongoClient } = require('mongodb');
  dns.setServers(['8.8.8.8', '1.1.1.1']);                   // as the project's test:integration script does
  
  const PROBE_DB = 'ccprobe';
  const PROBE_USER = 'ccprobe-temp';
  
  const uri = process.env.MONGODB_URI;
  if (!uri) { console.log('MONGODB_URI not set in the env file'); process.exit(2); }
  
  let host = '', user = '', pass = '';
  try { const u = new URL(uri); host = u.hostname; user = decodeURIComponent(u.username); pass = decodeURIComponent(u.password); }
  catch { console.log('URI could not be parsed; refusing'); process.exit(2); }
  const secrets = [uri, host, user, pass].filter((s) => s && s.length > 2);
  const redact = (s) => {
    let out = String(s);
    for (const x of secrets) out = out.split(x).join('[redacted]');
    return out.replace(/[A-Za-z0-9._-]*mongodb\.net(:\d+)?/g, '[redacted-host]').replace(/mongodb(\+srv)?:\/\/\S+/g, '[redacted-uri]');
  };
  
  if (!host.includes('civicconnecttest')) { console.log('Host check FAILED: not the test cluster; refusing to connect'); process.exit(2); }
  console.log('Host check passed (host contains the test-cluster marker; host not printed).');
  console.log(`Probe database: ${PROBE_DB}. Run started (UTC): ${new Date().toISOString()}`);
  console.log(`Node ${process.version}; driver mongodb ${require('mongodb/package.json').version}`);
  
  const errOf = (e) => ({ ok: false, code: e.code, codeName: e.codeName, msg: redact(e.errmsg || e.message) });
  const show = (r) => (r.ok ? `ok ${r.detail ?? ''}` : `refused/failed: code ${r.code} ${r.codeName ?? ''} — ${r.msg}`);
  
  const client = new MongoClient(uri, { serverSelectionTimeoutMS: 15000 });
  try {
    await client.connect();
  } catch (e) {
    console.log(`Could not connect: ${show(errOf(e))}`); process.exit(2);
  }
  const db = client.db(PROBE_DB);
  
  // 0. Who are we, and what may we do? (server-reported; the user name is checked, not printed)
  try {
    const st = await client.db('admin').command({ connectionStatus: 1, showPrivileges: true });
    const users = st.authInfo.authenticatedUsers.map((u) => u.user);
    console.log(`\n0. Authenticated as the probe user (${PROBE_USER}): ${users.includes(PROBE_USER) ? 'yes' : 'NO'}`);
    console.log('   Privileges reported by the server:');
    for (const p of st.authInfo.authenticatedUserPrivileges) {
      const r = p.resource;
      const where = r.anyResource ? 'anyResource' : r.cluster ? 'cluster' : `${r.db || '(any db)'} / ${r.collection || '(any collection)'}`;
      console.log(`     ${where} : ${p.actions.join(', ')}`);
    }
    if (!users.includes(PROBE_USER)) { console.log('Not the probe user; stopping.'); await client.close(); process.exit(2); }
  } catch (e) {
    console.log(`0. connectionStatus: ${show(errOf(e))}`);
  }
  
  const steps = [
    ['1', 'Control: listIndexes on ccprobe.absent_a (does not exist)',
      'refused with 26 NamespaceNotFound (shows listIndexes is granted and the collection is absent)',
      async () => { await db.collection('absent_a').listIndexes().toArray(); return { ok: true }; }],
    ['2', 'Negative control: insertOne into ccprobe.absent_b',
      'refused (Unauthorized 13, or Atlas 8000): the credential is not broader than intended',
      async () => { await db.collection('absent_b').insertOne({ probe: 1 }); return { ok: true }; }],
    ['3', 'Negative control: explicit createCollection ccprobe.absent_c',
      'refused (createCollection is not granted to this role)',
      async () => { await db.createCollection('absent_c'); return { ok: true }; }],
    ['4', 'QUESTION A: createIndexes {k: 1} on ccprobe.absent_a (does not exist)',
      'no prediction; (a) ok with createdCollectionAutomatically true = createCollection NOT needed; (b) refused naming createCollection/create = needed; (c) refused naming createIndex = role misconfigured',
      async () => { const r = await db.command({ createIndexes: 'absent_a', indexes: [{ key: { k: 1 }, name: 'k_1' }] });
        return { ok: true, detail: `createdCollectionAutomatically=${r.createdCollectionAutomatically} numIndexesBefore=${r.numIndexesBefore} numIndexesAfter=${r.numIndexesAfter}` }; }],
  ];
  const results = {};
  for (const [n, what, expected, fn] of steps) {
    let r; try { r = await fn(); } catch (e) { r = errOf(e); }
    results[n] = r;
    console.log(`\n${n}. ${what}\n   Expected: ${expected}\n   Actual:   ${show(r)}`);
  }
  
  if (results['4'].ok) {
    const more = [
      ['5', 'Idempotency: the same createIndexes {k: 1} again', 'ok, numIndexesBefore = numIndexesAfter (nothing created)',
        async () => { const r = await db.command({ createIndexes: 'absent_a', indexes: [{ key: { k: 1 }, name: 'k_1' }] });
          return { ok: true, detail: `numIndexesBefore=${r.numIndexesBefore} numIndexesAfter=${r.numIndexesAfter} note=${r.note ?? ''}` }; }],
      ['6a', 'QUESTION B setup: createIndexes {t: 1} name t_1, expireAfterSeconds 1800', 'ok',
        async () => { await db.command({ createIndexes: 'absent_a', indexes: [{ key: { t: 1 }, name: 't_1', expireAfterSeconds: 1800 }] }); return { ok: true }; }],
      ['6b', 'QUESTION B: same key and name, expireAfterSeconds 1801', 'refused with 85 IndexOptionsConflict',
        async () => { await db.command({ createIndexes: 'absent_a', indexes: [{ key: { t: 1 }, name: 't_1', expireAfterSeconds: 1801 }] }); return { ok: true }; }],
      ['6c', 'QUESTION B check: listIndexes on ccprobe.absent_a', '_id_, k_1, t_1 with expireAfterSeconds 1800 (unchanged)',
        async () => { const ix = await db.collection('absent_a').listIndexes().toArray();
          return { ok: true, detail: ix.map((i) => `${i.name}${i.expireAfterSeconds !== undefined ? ` (expireAfterSeconds ${i.expireAfterSeconds})` : ''}`).join(', ') }; }],
    ];
    for (const [n, what, expected, fn] of more) {
      let r; try { r = await fn(); } catch (e) { r = errOf(e); }
      results[n] = r;
      console.log(`\n${n}. ${what}\n   Expected: ${expected}\n   Actual:   ${show(r)}`);
    }
  } else {
    console.log('\n5-6. Skipped: step 4 did not create the collection, so there is nothing to test question B on.');
  }
  
  const a = results['4'];
  const named = (r, re) => !r.ok && re.test(`${r.msg} ${r.codeName}`);
  console.log('\nCONCLUSION A: ' + (a.ok ? 'createIndexes on an absent collection succeeded WITHOUT createCollection.'
    : named(a, /createCollection|\bcreate\b/i) ? 'createIndexes on an absent collection NEEDS createCollection.'
    : named(a, /createIndex/i) ? 'refused naming createIndex: the role is misconfigured; fix it and re-run.'
    : 'inconclusive: refused without naming an action; see the message above.'));
  if (results['6b']) console.log('CONCLUSION B: ' + (results['6b'].code === 85 ? 'a different expireAfterSeconds is refused with 85 IndexOptionsConflict'
    : results['6b'].ok ? 'a different expireAfterSeconds was ACCEPTED (unexpected); see 6c' : `refused with ${results['6b'].code} ${results['6b'].codeName}`)
    + (results['6c']?.ok ? `; listing after: ${results['6c'].detail}` : ''));
  console.log(`Run ended (UTC): ${new Date().toISOString()}`);
  await client.close();
